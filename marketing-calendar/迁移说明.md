# 换电脑迁移说明

如已收到含内嵌 Python 的便携版 ZIP，请直接阅读包内 `迁移说明_便携版.txt`；下文是从仓库源码安装的方式。

## 1. 在新电脑获取代码

安装 Git、Python 3.10～3.13、Microsoft Edge 和桌面版 Microsoft Excel；然后克隆仓库。目录可自行选择，不依赖固定盘符或用户名。

```powershell
git clone https://github.com/newyang2024/ecommerce-toolkit.git
cd ecommerce-toolkit\marketing-calendar
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item config\config.example.json config\config.json
.venv\Scripts\python.exe main.py check
```

`config.json` 中的 `output`、`logs`、`browser_profile` 默认相对项目目录解析；如需改位置，只修改新电脑自己的 `config.json`。不要把它提交到 Git。

## 2. 迁移业务输入

将**已确认匹配源正确、公式行足够**的日报表底本通过可信的私人方式复制到新电脑，并在界面选择它。该大型 Excel 不在仓库中。原电脑的 `output/`、下载 CSV、运行清单只在需要复查或离线重跑时再单独转移；普通使用可在新电脑重新下载。不要把这些文件上传到公开仓库。

浏览器配置与登录态不迁移；在新电脑启动项目专用 Edge，重新手动登录。若网站出现安全验证，按界面提示人工完成后再续跑，不重复提交结果不明的下载任务。

## 3. 启动与验收

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -v
.venv\Scripts\python.exe main.py gui
```

也可在 `marketing-calendar/` 中双击 `启动营销日历工具.bat`。首次试跑建议先用 `main.py check` 检查依赖，再用界面完成登录、下载和整理；核对输出日期、五份 CSV、透视表以及关注的型号名称。Excel 透视表刷新需要本机安装的桌面版 Excel。

## 4. 在 Codex 中使用新目录

在 Codex 的项目或打开文件夹入口选择**克隆后的 `ecommerce-toolkit` 文件夹**，以后在该项目中开启代码任务。原 `营销日历工具` 文件夹保留作历史备份，不再作为代码修改来源。开始下一次开发前，先同步仓库并检查本地 Git 改动；在功能分支修改、测试并提交 PR。

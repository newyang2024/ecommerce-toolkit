# ecommerce-toolkit
跨平台电商数据采集、价格监测与经营分析工具箱

目前纳入仓库的工具：

- [营销日历工具](marketing-calendar/README.md)：在 Windows 上下载五类万相台报表，并整理到现有 Excel 底本。
- [主图识别工具](main-image-tool/README.md)：读取竞品天猫商品链接，用 OCR 识别营销主图上的活动时间、价格和权益，回填本地 Excel 并生成人工复核清单。

代码与测试以本仓库为后续维护来源。真实报表、链接库、登录状态和日报表底本不提交到 Git；营销日历工具换电脑的操作见[迁移说明](marketing-calendar/迁移说明.md)，主图识别工具的迁移与运行见[主图识别工具说明](main-image-tool/README.md)。

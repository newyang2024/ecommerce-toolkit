# 天猫主图智能信息提取工具 使用说明

## 一、工具用途
读取本地链接库里的竞品（美的、海尔冰箱）天猫商品链接，自动打开商品详情页，定位营销主图，用 OCR 识别图上的活动时间、价格和权益（赠品、保障权益、红包、其他），结果回填到本地 Excel，并生成一份人工复核清单。

## 二、启动方式
双击项目目录下 `05_程序\启动工具.bat`，即可打开桌面工具。

## 三、操作步骤

1. 启动浏览器
   点右上角"启动浏览器"，会打开一个专用 Edge（独立配置，调试端口 9223）。
   第一次使用请在这个浏览器里登录天猫。

2. 确认登录
   登录后点"重新检测"，顶部"浏览器"和"登录"两个状态灯变绿就可以开始。

3. 开始采集
   在"采集控制"标签页：
   - 选"全部商品"跑完整链接库，或选"前 N 个"只跑一部分。
   - 勾"断点续跑"会自动跳过已经完成的商品，中途停了下次接着跑。
   - 点"开始采集"，能看到进度条、当前商品、成功失败统计和实时日志。
   - 需要中断点"停止采集"，会在当前商品结束后退出，进度自动保存。

4. 查看结果
   在"结果查看"标签页：
   - 按品牌、门体、状态筛选，点列标题排序。
   - 点"导出 Excel"把当前筛选结果另存，或"打开结果所在文件夹"。

5. 人工复核
   在"复核清单"标签页看待核对项，按原因筛选，只展示不编辑。
   确认后在导出的 Excel 里人工核对即可。

## 四、输出文件位置
都在 `06_结果输出` 目录：
- 结果表：`竞对主图识别结果_时间戳.xlsx`
- 复核清单：`人工复核清单_时间戳.md`
- 营销主图：`营销主图\` 文件夹
- OCR 原始结果：`ocr原始结果\` 文件夹
- 运行日志：`日志\` 文件夹
- 断点进度：`进度\pipeline_state.json`

## 五、注意事项
- 工具只读取公开的主图信息，不做下单、不交互，访问频率已控制。
- 连续打开约 35 个商品后页面可能出现"访问异常"，这是天猫对页面的限制，不影响主图加载，工具会继续抓取，不用等冷却。
- 活动未开始时，主图价格位置可能是问号，这是商家原图，不是出错，活动开始后重跑即可补全。
- 链接库更新后，替换 `04_链接库\竞对AI价格表_本地链接库.xlsx`，重启工具会自动读取。
- 命令行方式仍可使用：`python run.py --limit N` 或 `python run.py --no-resume`。

# 天猫商品页控件清单（真机探查）

探查时间：2026-10-29，已登录天猫，覆盖美的、海尔共 6 个商品，含视频商品和多颜色价格商品。

## 一、页面整体布局

商品详情页从上到下、从左到右：

- 顶部：天猫导航、搜索框
- 左侧：主图缩略图列表（竖向）
- 中间：主图大图区
- 右侧：商品标题、价格、加入购物车、领券购买、SKU 选择
- 下方：商品详情描述（长图，descV8）

## 二、媒体区结构（核心）

类名是 CSS Modules 混淆的，带哈希后缀，但前缀稳定，统一用前缀包含匹配。

| 区域 | 选择器（稳定写法） | 说明 |
|---|---|---|
| 主图容器 | `[class*="mainPicWrap"]` | 主图外层，约 388x388 |
| 主图图片 | `[class*="mainPic--"]` | 当前显示的大图 |
| 缩略图列表 | `[class*="thumbnailsWrap"]` | 竖向缩略图容器 |
| 单个缩略图 | `[class*="thumbnail--"]` | 可点击的缩略图项 |
| 缩略图图片 | `[class*="thumbnailPic"]` | 缩略图里的图片 |
| 视频播放按钮 | `[class*="playerIcon"]` | 主图区有视频时出现 |
| 其他图入口 | `[class*="thumbnailOtherPic"]` | 缩略图末尾的特殊项 |

## 三、营销主图定位规律（关键结论）

1. 每个商品有 8 到 9 个缩略图位置，前 6 个是实际图片，末尾 2 到 3 个是空占位。
2. 第一张缩略图就是营销主图，文件名都含 `picasso.jpg`，包含价格、活动时间、权益。
3. 缩略图第 0 和第 1 个位置通常是同一个 URL（视频封面或营销图重复）。
4. 第二张图常是带权益的场景图，可作为权益识别的补充；再往后是功能、参数图，不用关注。
5. 这个规律对美的、海尔都适用，有视频的商品也一样，营销主图仍是第一张。

## 四、高清图 URL 规律

缩略图拿到的是压缩版，例如：

```
https://gw.alicdn.com/imgextra/O1CN01G8zK6FZc26I1chua_!!201749140-0-picasso.jpg_q50.jpg_.webp
```

- 去掉 `_q50.jpg_.webp` 后缀，再补 `.jpg` 或 `.png`，就是高清原图。
- 原图为正方形，营销图常见 1440x1440 或更高。
- 直接下载 URL 即可，不需要点击缩略图切换，减少交互。

## 五、视频处理

- 部分商品第一张是视频或带视频入口，主图区出现 `playerIcon`。
- 即使第一张是视频，其封面图（picasso.jpg）仍包含营销信息，直接用封面图即可。
- 本工具不需要播放视频，只取封面图。

## 六、SKU 选择区

| 区域 | 选择器 | 说明 |
|---|---|---|
| SKU 容器 | `[class*="skuWrapper"]` | 版本和颜色分类 |
| SKU 项 | `[class*="skuItem"]` | 单个维度 |
| SKU 值 | `[class*="skuValueWrap"]` | 具体颜色选项 |

- SKU 里会列出颜色全名，例如 `MR-631WUSJDLZE 601L流光白`、`601L流光黛`。
- 多颜色价格商品可参考 SKU 里的颜色名做对应。
- 本工具只读不切换 SKU，信息以营销主图为准。

## 七、价格形态与对应口径

- 单一价格：主图只标一个价，不区分颜色，所有相关行直接填，例如行5 价格 5199。
- 多颜色价格：主图按颜色分别标价，需要颜色对应，例如行6 灰色 4899、白色 4999。
- 双色同价：两个颜色标同一个价，都填这个价。

## 八、对后续模块的指引

- image_locator 直接找第一张缩略图，构造高清 URL 下载，不点击、不切换。
- 类名匹配一律用前缀包含，不写死哈希。
- 下载图片失败时再回退到主图截图。
- 频率控制沿用配置，商品之间间隔、分批长休息。

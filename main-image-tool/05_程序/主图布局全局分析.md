# 营销主图布局全局分析

分析时间：2026-10-29，基于三种模板图和真机抓取的真实营销图。坐标用相对位置，x 从左到右、y 从上到下，范围 0 到 1。

## 一、主图整体结构

营销主图是正方形，常见 1440x1440，整体分四个区域：

- 顶部横幅，y 0 到 0.12：品牌 logo、天猫双11、卖点标签，基本不用关注
- 左侧文字区，x 0 到 0.42：标题、卖点、价格、权益、时间的主战场
- 右侧产品区，x 0.4 到 1：产品图、代言人，基本不含目标信息
- 底部信息带，y 0.75 到 1：价格、时间、服务承诺

核心结论：目标信息九成集中在左侧约四成宽度和底部约两成半高度，右侧和顶部是装饰。但模板二的价格和权益都在左侧，所以左侧要完整识别，不能只裁某一块。

## 三、各字段常出现位置和特征

### 价格

- 字号最大、最醒目，通常带 ¥ 符号或“到手价、活动价、到手”引导。
- 位置不固定，底部左下或右下都有，模板二在左中，所以不能只看某一个角。
- 多价格时，价格旁边会标颜色或门型，如灰色、白色、十字、法式。
- 双色同价会明确写“双色同价”，或两个颜色位置标同一个数。

### 权益

- 通常在左侧中部，竖排卡片或红底标签。
- 赠品带“送、加赠、预约加赠”，红包带“返、红包、瓜分、晒单”，保障带“保修、包换、延保、质保”。
- 模板二权益最丰富，集中在左下半。
- 第二张图常是权益专图，权益列得更清楚，作为补充。

### 时间

- 通常跟随价格或在权益区，也有写在底部横幅。
- 写法：“X 日 X 点到 X 日 X 点”“X 日 X 点开抢”“X 日 X 点首小时”。
- 单个时点如实记录，不臆测结束时间。

## 四、抓取逻辑

1. 打开商品页，定位第一张缩略图，即营销主图，文件名含 picasso。
2. 从缩略图 URL 构造高清原图下载，不点击、不切换。
3. 同时下载第二张图，作为权益识别补充。
4. 下载失败时，回退到主图区域截图。
5. 类名一律用前缀包含匹配，避开哈希后缀。

## 五、对后续识别模块的指引

- OCR 识别全图，不预先裁剪区域，靠位置和关键词判断，避免漏掉模板差异。
- 价格提取要在全图找最大金额，并结合位置和引导词，不能只盯一个角。
- 权益提取以第一张为主，识别不全时结合第二张图。
- 位置信息作为辅助判断，关键词和正则为主，位置用于消歧。
- 多价格才启用颜色归并，单一价格直接填，不做颜色对应。
